# 💰 Tip Calculator

A beginner Python project that calculates a tip and splits the total bill between multiple people.

## 💻 About the Project

The Tip Calculator asks the user for the total bill, the percentage they would like to tip, and the number of people splitting the bill.

The program then calculates the total bill including the tip and determines how much each person should pay.

I completed this project while working through the 100 Days of Code: The Complete Python Pro Bootcamp. This project helped me practice working with numbers, user input, calculations, and formatting output in Python.

## 🛠️ Skills Practiced

- Type conversion with `float()` and `int()`
- Arithmetic operations

- Formatting decimal values

## 🧮 How It Works

The program:

1. Asks for the total bill.
2. Asks what percentage the user would like to tip.
3. Asks how many people are splitting the bill.
4. Calculates the tip amount.
5. Adds the tip to the original bill.
6. Divides the total between the number of people.
7. Displays how much each person should pay.

## ▶️ How to Run

Make sure Python is installed, then run:

`python tip_calculator.py`

Follow the prompts in the terminal to calculate the amount each person should pay.
